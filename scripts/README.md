# Scripts

- `install.sh`: copia el plugin al perfil de Krita (backup del `kritarc`).
- `uninstall.sh`: lo retira y deja todo como estaba.
- `build_core.sh`: compila el motor Rust.
- `build_native.sh`: compila el shim para una versión de Krita.

Ninguno toca la instalación de Krita ni requiere root.
